# haradoke-legal

おにうさ(iOS アプリ。2026-11-17 に「ハラドケ」から改名。リポジトリ名と URL は変えない)の法務ページ(プライバシーポリシー・特定商取引法に基づく表記)。GitHub Pages で公開する。文の正本はこのリポジトリの公開中の HTML。仕様の参照先は ta1pre/fasting168 の design/spec.md 19章。

## お問い合わせ

App Store のサポート URL には `/support/` の問い合わせページを使う。アプリの使い方・不具合・ご要望は、法務ページに掲載しているメール窓口で受け付ける。

### 文字と余白

| 項目 | 文字サイズ / 行の高さ | 文字の画素の上下端 |
| --- | --- | --- |
| アプリ名 | 16 / 24px | 32–48px |
| 見出し | 24 / 32px | 88–112px |
| 案内 | 15 / 24px | 128–144px、152–168px |
| メールアドレス | 16 / 24px | 192–208px |
| 法務リンク | 15 / 24px | 264–280px。次の行に回る場合は 304–320px |

ページの上下は 32 / 48px、左右は 24px。メールリンクの高さは 56px、法務リンクは 40px。320px、393px、1280px 幅で、文字の画素の上下端はページ上端から測り誤差 1px まで。案内の最終行だけが 1～2 文字になる改行と横方向のはみ出しを防ぐ。
